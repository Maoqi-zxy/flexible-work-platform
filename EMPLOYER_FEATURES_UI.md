## 🎨 设计规范

### 颜色使用
- **主色调**: `primary-600` (品牌色)
- **成功**: `green-600` / `bg-green-100 text-green-800`
- **警告**: `yellow-600` / `bg-yellow-100 text-yellow-800`
- **危险**: `red-600` / `bg-red-100 text-red-800`
- **信息**: `blue-600` / `bg-blue-100 text-blue-800`

### 组件样式
- **卡片**: `bg-white rounded-xl shadow-sm border border-gray-200`
- **按钮**: `btn-primary` (主按钮), 自定义状态按钮
- **徽章**: `px-3 py-1 rounded-full text-xs font-medium`
- **标签**: `px-3 py-1 bg-gray-100 text-gray-700 rounded-full text-xs`

### 响应式
- 移动端：单列布局
- 桌面端：充分利用宽度的卡片布局
- 导航栏：移动端隐藏，桌面端显示

## 📱 用户操作流程

### 企业用户审核流程

1. **登录** → 企业用户账号
2. **导航** → 点击顶部导航"雇主管理"
3. **查看任务** → 浏览已发布任务列表
4. **选择任务** → 点击任务的"查看申请"按钮
5. **浏览申请** → 查看所有自由职业者的申请
6. **审核申请** → 点击"通过"或"拒绝"
7. **确认操作** → 在确认对话框中确认
8. **查看结果** → Toast 提示操作结果
9. **状态更新** → 申请状态实时更新

## 📊 数据流

````
前端页面
    │
    ├─ GET /api/employer/tasks
    │   └─ 返回任务列表 (包含 submissionCount)
    │
    ├─ GET /api/tasks/:id/submissions
    │   └─ 返回申请列表 (包含 freelancer 信息)
    │
    ├─ POST /api/submissions/:id/approve
    │   └─ 更新申请状态为 accepted
    │
    └─ POST /api/submissions/:id/reject
        └─ 更新申请状态为 rejected
```
